プライバシーポリシー

最終更新日: 2026 年 10 月 30 日

calendar-sync（以下「本ツール」）が Google アカウントから取得する情報と、その扱いについて定めます。

本ツールの性質

本ツールは、開発者本人が自分の管理する複数の Google アカウントのカレンダーを同期するために作成した個人用のプログラムです。利用者自身の機器で動作し、開発者や第三者が運営するサーバーを介しません。

取得する情報

利用者が Google の同意画面で許可した各アカウントについて、Google API を通じて次の情報を取得します。

  • アカウントのメールアドレス（同意したアカウントが設定どおりのものであるかの確認に使います）
  • カレンダーの予定の識別子、開始・終了の日時、繰り返しの設定、状態（確定・削除・空き時間扱いなど）、自分の出欠の回答、更新日時
  • 予定の件名、場所、説明、参加者などは Google API の応答に含まれますが、本ツールはこれらを保存せず、他のアカウントへも写しません

利用目的

取得した情報は、同期対象のアカウントの間で予定の有無を揃えるためだけに使います。具体的には、あるアカウントの予定と同じ日時に、他のアカウントのカレンダーへタイトル「予定あり」の予定を作成・更新・削除します。広告、分析、プロファイリング、人工知能モデルの学習などには使いません。

保存と保護

  • Google から受け取ったアクセストークンと更新トークン、および元の予定と複製した予定の対応表（予定の識別子と更新日時）を、利用者自身の機器の、所有者以外が読めない領域に保存します
  • 予定の内容（件名、場所、説明、参加者）は保存しません
  • Google のサーバー以外へデータを送信しません

第三者への提供

取得した情報を第三者へ販売、提供、共有することはありません。

Google API サービスのユーザーデータに関するポリシーへの準拠

本ツールによる Google API から受け取った情報の利用、および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。

calendar-sync's use and transfer to any other app of information received from Google APIs will adhere to Google API Services User Data Policy, including the Limited Use requirements.

データの削除とアクセスの取り消し

  • Google アカウントの「サードパーティ製のアプリとサービス」から本ツールのアクセスを取り消すと、本ツールはそのアカウントへアクセスできなくなります
  • 機器に保存したトークンと対応表は、利用者がファイルを削除することでいつでも消去できます
  • 本ツールが作成した「予定あり」の予定は、Google カレンダー上で削除できます

ポリシーの変更

本ポリシーを変更する場合は、このページで公開し、最終更新日を更新します。

お問い合わせ

本ポリシーに関する問い合わせは、Google の同意画面に表示されるサポート用メールアドレスまでお願いします。
